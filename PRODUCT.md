# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Personas que visitan el perfil público de GitHub de Leonard: estudiantes y desarrolladores que quieren conocer su trabajo, además de posibles colaboradores o clientes que evalúan sus proyectos.

## Product Purpose

Presentar a Leonard como estudiante de Ingeniería en Computación y creador de productos digitales. El perfil debe mostrar trabajo concreto y conducir principalmente a su portafolio en `leonardsf.dev`.

## Positioning

Leonard aprende construyendo herramientas para problemas reales, especialmente productos web, automatización y soluciones para estudiantes y pequeños negocios.

## Capabilities and Constraints

- El artefacto es un README de perfil de GitHub; debe funcionar con el Markdown y el HTML que GitHub admite.
- No puede depender de JavaScript, CSS personalizado ni interacciones propias.
- Debe conservar MI SAES 2.0, Mi Horario ESIME, el bot de citas y LeonardSF.dev como trabajo destacado.
- El enlace principal es `https://leonardsf.dev/`; GitHub y Telegram son secundarios.

## Brand Commitments

- Nombre público: Leonard / LeonardSF.
- Voz: directa, personal y en español; estudiante y creador antes que agencia o marca corporativa.
- Evitar copy genérico, afirmaciones infladas y adornos que parezcan generados automáticamente.
- El hero técnico contiene la identidad principal; no repetir debajo el nombre, la especialidad ni la foto que GitHub ya muestra en el perfil.

## Evidence on Hand

- README existente con proyectos, tecnologías y enlaces.
- Portafolio público: `https://leonardsf.dev/`.
- Proyecto MI SAES 2.0 documentado en el entorno local de trabajo.
- Sitio público Mi Horario ESIME: `https://mihorarioesime.com`.

## Product Principles

- Los proyectos demuestran el perfil; los adjetivos no.
- La lectura debe llegar rápidamente del nombre al trabajo y del trabajo al portafolio.
- Cada sección debe aportar información nueva.
- Usar pocos elementos externos y sólo cuando mejoren la comprensión.

## Accessibility & Inclusion

Mantener textos alternativos útiles, contraste legible en temas claro y oscuro, y una estructura comprensible sin depender de imágenes.
